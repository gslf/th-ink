th.ink / private keys

Open this file locally in your browser. It works offline, sends nothing and stores nothing. Generate a different key for each purpose.

For setup, enter this on the HTTPS setup page. For cron rotation, use it as the X-Cron-Secret header in cron-job.org. Never put it in a URL or upload it in a config file. Place the file in think-private, beside www. This contains only the SHA-256 verifier of your random 256-bit key. When resetting the owner password, use this as setup_key_hash in the existing private config. When rotating cron, use cron_secret_hash. Preserve the other settings; do not replace an existing configuration with the first-installation example above.
